# Production 3-tier on AWS (Terraform + containers + MySQL)

```
app/                      Spring Boot Dockerfile (multi-stage, non-root)
infra/
├── modules/
│   ├── network/          VPC, 3 subnet tiers x 3 AZs, NAT, endpoints, flow logs
│   └── rds/              MySQL 8.4, KMS, Multi-AZ, managed secret
└── envs/dev/             Wires the modules together
```

Coming next: `ecr`, `alb`, `ecs-service`, `monitoring`, GitHub Actions (OIDC), staging/prod envs.

## 1. Create the remote state bucket (one time)

```bash
BUCKET=my-unique-tfstate-bucket   # must be globally unique
REGION=eu-north-1

aws s3api create-bucket --bucket $BUCKET --region $REGION \
  --create-bucket-configuration LocationConstraint=$REGION
aws s3api put-bucket-versioning --bucket $BUCKET \
  --versioning-configuration Status=Enabled
aws s3api put-bucket-encryption --bucket $BUCKET \
  --server-side-encryption-configuration \
  '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
aws s3api put-public-access-block --bucket $BUCKET \
  --public-access-block-configuration \
  BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
```

## 2. Deploy dev

```bash
cd infra/envs/dev
cp backend.hcl.example backend.hcl      # put your bucket name in it
terraform init -backend-config=backend.hcl
terraform fmt -recursive ../..
terraform validate
terraform plan -out tfplan
terraform apply tfplan
```

## 3. Build the image (Docker or Podman, same Dockerfile)

```bash
cd app
docker build -t myapp:local .
# or
podman build --format docker --platform linux/amd64 -t myapp:local .
```

## Notes
- `require_secure_transport=1` is on: MySQL clients must use TLS. The default Connector/J `sslMode=PREFERRED` negotiates it; for stricter verification use `sslMode=VERIFY_CA` with the RDS CA bundle.
- DB credentials are generated by RDS into Secrets Manager (`db_secret_arn` output); inject them into ECS via the task definition `secrets` block.
- Dev trims cost: one NAT gateway, no interface endpoints, single-AZ DB, no deletion protection. Prod flips all of these.
- Pin the exact MySQL minor version in prod instead of `8.4`.
